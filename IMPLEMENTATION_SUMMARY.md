Backend API (Laravel 11)\n\n#### Controllers\n```\napp/Http/Controllers/Api/\n├── BaseController.php          - Unified response handling\n├── AuthController.php          - Login, Logout, User profile\n├── QuestionnaireController.php - Advanced analytics\n├── ExportController.php        - PDF, Excel, CSV export\n└── SuggestionController.php    - Suggestion/comment management\n```\n\n#### Models\n```\napp/Models/\n├── User.php              - Individual question scores\n└── Suggestion.php        - User comments/suggestions\n```\n\n#### Database\n```\nDatabase Tables:\n├── users                 - Admin/Staff accounts\n├── questionnaires       - Delete survey\nPOST   /api/surveys/{id}/questions  - Add question\nPUT    /api/questions/{id}          - Update question\nDELETE /api/questions/{id}          - Delete question\nGET    /api/responses               - Get all responses\nGET    /api/admin/dashboard         - Dashboard stats\nGET    /api/analytics/overview      - Analytics overview\nGET    /api/analytics/categories    - Category analysis\nGET    /api/export/pdf              - Export PDF\nGET    /api/export/excel            - Export Excel\nGET    /api/export/csv              - Export CSV\nGET    /api/suggestions             - List suggestions\nGET    /api/suggestions/{id}        - Get suggestion\nDELETE /api/suggestions/{id}        - Delete suggestion\n```\n\n#### Middleware & Security\n```\napp/Http/Middleware/\n├── HandleCors.php           - CORS support\n└── ThrottleRequests.php     - Rate limiting\n\nconfig/\n├── cors.php                 - CORS configuration\n├── queue.php                - Job queue setup\n└── mail.php                 - Email configuration\n```\n\n#### Error Handling\n- **Unified Response Format**: All responses follow consistent JSON structure\n- **Validation Errors**: Field-specific error messages\n- **Status Codes**: Proper HTTP status codes (200, 201, 204, 400, 401, 404, 422, 500)\n- **Try-Catch Blocks**: All controller methods have error handling\n\n---\n\n### 2.
