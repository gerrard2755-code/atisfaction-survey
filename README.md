# ระบบประเมินความพึงพอใจการใช้งานเว็บไซต์
## Website Satisfaction Survey System

ระบบประเมินความพึงพอใจการใช้งานเว็บไซต์ แบบครบวงจร พร้อมฟีเจอร์วิเคราะห์ข้อมูลและรายงาน

### 🎯 Features
- ✅ แบบประเมินแบบตอบได้จากคอมพิวเตอร์และมือถือ
- ✅ ระดับคะแนน 5 ระดับ
- ✅ ป้องกันการส่งซ้ำ
- ✅ Dashboard สำหรับผู้ดูแลระบบ
- ✅ วิเคราะห์ข้อมูลแบบ Real-time
- ✅ ส่งออกรายงาน PDF, Excel, CSV
- ✅ Role-based Access Control

### 📦 Tech Stack
- **Frontend**: HTML5, CSS3, Bootstrap 5, Vue.js
- **Backend**: Laravel PHP
- **Database**: MySQL
- **Charts**: Chart.js, ApexCharts
